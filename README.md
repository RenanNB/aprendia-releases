# AprendIA · Descargas oficiales

Aplicación Android de **NLX Labs** para preparar exámenes de ingreso con bancos de preguntas y materiales de estudio. Derecho UMSA 2026 es el primer banco incluido, sin afiliación universitaria.

Este repositorio es público y contiene únicamente información de distribución y APK firmadas. El código de desarrollo se mantiene en un repositorio privado separado.

**[Descargar la versión más reciente](https://github.com/RenanNB/aprendia-releases/releases/latest)**

- **General:** apoyo neutral y experiencia para estudiantes.
- **Pareja · Para vos:** vino mate, arte romántico original y mensajes personales.

**Novedades de 1.1.0:** baraja que podés girar, deslizar, mezclar y ordenar; aprendizaje guiado y recuerdo escrito; juegos de selección múltiple y verdadero/falso; lector con índice, búsqueda, subrayados, marcadores, notas y continuidad; importación local de PDF, Word y texto; piano real disponible sin conexión.

Android 8.0 o posterior. Elegí la variante correspondiente. Ambas pueden coexistir con progresos independientes. Instalá una actualización sobre la misma variante para conservar tus datos. Android solicita los permisos de instalación correspondientes; la app no instala APK en silencio.

El canal oficial es `RenanNB/aprendia-releases`: consultar y descargar versiones no requiere cuenta ni token. Cada release adjunta APK, checksums y metadatos.

El banco inicial tiene 2.018 tarjetas con fuente, 160 actividades de selección múltiple con explicación y 64 V/F. Las demás tarjetas conservan respuesta citada, sin explicación ampliada revisada. El lector incluye el PDF original; los PDF escaneados pueden verse sin OCR automático. La IA es opcional, requiere una clave propia y consentimiento; sus propuestas y evaluaciones deben contrastarse con la fuente. La aplicación no garantiza calificaciones ni certifica de forma independiente el contenido.
