# AprendIA · Descargas oficiales

Aplicación Android de **NLX Labs** para preparar exámenes de ingreso con bancos de preguntas y materiales propios. Derecho UMSA 2026 es el primer banco incluido, sin afiliación universitaria.

Este repositorio es público y contiene únicamente información de distribución y APK firmadas. El código de desarrollo se mantiene en un repositorio separado.

**[Descargar la versión más reciente](https://github.com/RenanNB/aprendia-releases/releases/latest)**

- **General:** apoyo neutral y experiencia para estudiantes.
- **Pareja · Para vos:** vino mate, arte romántico original y mensajes personales.

Android 8.0 o posterior. Elegir la variante correspondiente. Ambas pueden coexistir; sus progresos son independientes. Las actualizaciones de la misma variante conservan datos locales y firma. Android pide autorización de instalación cuando corresponda; la app no instala APK en silencio.

El canal oficial de actualizaciones es `RenanNB/aprendia-releases`: consultar y descargar versiones no requiere cuenta ni token. Las APK y sus hashes están adjuntas en cada release.

El banco inicial tiene 2.018 tarjetas con fuente, 160 actividades de selección múltiple con explicación y 64 V/F. Las demás tarjetas conservan respuesta citada, sin explicación ampliada revisada. Generación con IA opcional requiere clave propia y revisión. La aplicación no garantiza calificaciones ni certifica de forma independiente el contenido.
